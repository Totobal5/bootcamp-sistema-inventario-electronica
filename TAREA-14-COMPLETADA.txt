✅ VERIFICACIÓN POST-DEPLOY:
=============================================================================

1. Health Check:
   curl https://tu-app.up.railway.app/actuator/health
   → Esperado: {"status":"UP"}

2. Swagger UI:
   https://tu-app.up.railway.app/swagger-ui.html
   → Debe cargar interfaz completa

3. Register Usuario:
   POST /api/auth/register (ver API-TESTING.md)
   → Esperado: 200 OK

4. Login:
   POST /api/auth/login
   → Esperado: JWT token válido

5. Crear Componente:
   POST /api/componentes (con token)
   → Esperado: 201 Created

=============================================================================
🐛 TROUBLESHOOTING RÁPIDO:
=============================================================================

❌ Build Fallido
   → Revisar logs en Railway/Render dashboard
   → Verificar variables de entorno
   → Confirmar JWT_SECRET > 32 caracteres

❌ No Conecta PostgreSQL
   → Verificar PostgreSQL está "Active"
   → SPRING_DATASOURCE_URL correcta
   → Usuario/password correctos

❌ 401 Unauthorized
   → JWT_SECRET configurado
   → Token en header: Authorization: Bearer <token>
   → Token no expirado

❌ 503 Service Unavailable
   → Esperar 1-2 min (primera request)
   → Verificar logs de errores
   → Confirmar PORT=${PORT:8080}
